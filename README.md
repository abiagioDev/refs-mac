# Refs

App per macOS di Refs: la tua libreria di reference in una finestra, con il salvataggio rapido dalla barra dei menu.

**[Scarica l'ultima versione](https://github.com/abiagioDev/refs-mac/releases/latest)**: apri il DMG e trascina Refs in Applicazioni. Gli aggiornamenti arrivano da soli.

Richiede macOS 14 o successivo.
